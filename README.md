# Telegram Market Analyzer 🤖

Telegram bot for basic market analysis.

## Features

- Telegram commands
- Market data from Twelve Data
- Basic UP / DOWN / NEUTRAL analysis
- Runs continuously on Railway

## Commands

/start

/signal EUR/USD

/signal BTC/USD

## Environment Variables

The following variables are required:

TELEGRAM_TOKEN

TWELVE_DATA_API_KEY

## Run

python main.py
